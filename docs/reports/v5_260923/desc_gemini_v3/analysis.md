- 1,000개 출력 전체에 길이·어휘 패턴 검사를 수행했습니다. 별도로 25개 영상 간격의 체계적 표본 40개와 패턴 검사로 찾은 후보 등을 포함한 73개 설명을 전문 정독했습니다. 6개는 해당 장면의 제공 키프레임 전체와 대조했습니다.
- 아래 패턴 수치는 정확도, 정보 손실률, 저작권 위험, 지시 위반률이 아닙니다. 예컨대 'camera'나 'hair'는 정당한 핵심 정보일 수 있습니다. 이를 통해 검토 후보를 찾고 실제 문맥을 읽었습니다.
- 성공 장면 행에는 생성 provenance가 없으므로 모든 행의 원래 프롬프트·모델 설정을 독립적으로 확인한 것은 아닙니다. 현재 v2 텍스트와 저장된 desc_gemini 출력을 대조해 설계했습니다. `audit_manifest.json`에 표본과 프롬프트 SHA-256을 기록했습니다.

## 앞서 제안한 방향을 실제 데이터로 수정한 부분

1. **장르·형식 자체가 항상 빠지는 것은 아닙니다.** Gemini는 이를 이미 첫 문장에서 잘 포착하는 경우가 많습니다. v3의 초점은 그 뒤의 외형·프레임 나열을 구체적 설명 초점·기법·용도로 대체하는 것입니다.
2. **텍스트 제한에는 양방향 경계가 필요합니다.** 자막의 존재만 말하면 설명 목적을 놓치고, 문장별로 풀면 원문 대화를 복원하게 됩니다. '주제·설명 초점·비교 기준' 수준까지 허용하고, 대화·농담·서사의 전개는 제한했습니다.
3. **목적을 반드시 채우게 하지 않습니다.** 00039처럼 샘플에 주제가 드러나지 않을 수 있습니다. 현재 관찰 범위 안에서만 일반적으로 기술합니다.
4. **모든 콘텐츠를 행동 중심으로 통일하지 않습니다.** 미용·수납은 기법과 용도, 패션·풍경·인테리어·시각효과 영상은 외형·공간·스타일이 핵심일 수 있습니다.
5. **숫자를 전부 제거하지 않습니다.** 비교·작업을 구별하는 수치는 남기되 게임 점수·스탯의 단계별 나열을 기본값으로 삼지 않습니다.
6. **특정 이름을 전부 제거하지 않습니다.** 근거 있는 게임·도구·음식·장르 명칭은 구체성을 주므로 허용하고, 실존 인물 식별·계정명·연락처·워터마크는 제외합니다. 기억한 줄거리로 근거를 보충하지 못하게 했습니다.
7. **길이보다 정보 선택이 핵심입니다.** 권장은 80–180단어로 낮췄지만 하한을 강제하지 않고 최대 350단어는 유지했습니다. 출력 토큰 설정 1,024는 변경하지 않았습니다. 짧아졌다는 이유만으로 개선이라고 평가해서는 안 됩니다.

## 결과 및 후속 검증 기준

`scene_description_v3.md`는 자유 서술 한 문단을 유지하며 '주제·형식 → 구별되는 초점 → 관찰된 활동·대상·도구·변화'의 우선순위를 갖습니다. 문법적 Graph 구조나 고정 필드를 강요하지 않습니다. 촬영·UI·분위기가 실제 내용의 핵심인 경우에는 보존합니다.

실제 생성으로 v3의 효과를 검증하지는 않았습니다. 추후 동일 키프레임·모델·디코딩 조건의 별도 실행에서 다음을 함께 확인해야 합니다.

- 핵심 기법·비교 기준·용도·주제 보존: 00032, 00054, 00096, 00098, 00651.
- 채팅·서사 과잉 재구성 및 표식 전사 감소: 00269, 00753, 00850.
- 알려지지 않은 맥락을 추측하지 않는지: 00039.
- 분위기·시각효과·음악 영상 형식·혼합 편집 보존: 00341, 00776, 00906.
- 구체적 정보 밀도와 출력량을 함께 비교. 어휘 패턴 감소만으로 정확도 향상을 주장하지 않음.
- 현재 Description Summary는 행동 중심으로 정보를 선택할 수 있으므로 장면의 개선이 최종 Summary에 유지되는지도 별도로 확인. 이번 요청 범위인 장면 프롬프트만 작성함.
