## 5. 왜 이런 차이가 생기는가

현 프롬프트 정책을 읽었을 때의 설명이며, 원인을 통제 실험으로 확정한 것은 아닙니다.

1. **정보 선택의 첫 기준이 다릅니다.** Description v3는 구체적인 초점·비교·용도를 먼저 요구하고, Graph v5는 활동·대상·도구를 먼저 요구합니다. 개념 설명처럼 행동이 부수적인 콘텐츠에서 차이가 큽니다.
2. **topics가 일반 범주로 제한됩니다.** 최대 3개, 각 4단어 이내의 넓은 주제를 요구하므로 ‘화장’, ‘게임’, ‘교육’은 남지만 구체적인 관점이 밀릴 수 있습니다. 하지만 짧은 표현으로도 개선할 여지가 있습니다.
3. **스타일은 개체 속성으로만 담기 쉽습니다.** 머리색·의상은 Entities에 잘 들어가지만, 전체 영상의 가을빛·3D 마법 효과·팬 편집 같은 특징은 넣을 위치와 우선순위가 약합니다.
4. **이름을 제한하는 정책 차이도 있습니다.** Graph는 topics의 names를 제외하고 Description은 근거 있는 게임·장르 명칭을 허용합니다. 작품명·지역명 누락 전체를 모델 성능 탓으로 볼 수 없습니다. 명칭 보존 범위를 먼저 맞춰야 공정하게 비교할 수 있습니다.
5. **Actions의 빈칸을 채워도 Context 손실은 복구되지 않습니다.** 교육·비교 장면에서 가리키기·걷기·만지기를 더 추가하는 것은 주제의 구체성을 높이지 않습니다.

## 6. 우선순위와 다음 개선 방향

**1순위는 Context의 구체적인 초점입니다.** 기존 topics 안에서도 다음 정도의 짧은 표현을 우선할 수 있습니다. 아래는 개선 방향의 예시이며 새 모델 생성 결과가 아닙니다.

| 사례 | 현재의 일반적인 표현 | 보존할 수 있는 짧은 특성 |
|---|---|---|
| 00096 | makeup tutorial | `low-contrast makeup`; `heavy versus light makeup` |
| 00110 | educational explanation | `geographic location inference`; `climate clues` |
| 00121 | mobile game | `status effect testing`; `plant vulnerability comparison` |
| 00621 | mobile MOBA | `Awakening mode gameplay` |
| 00126 | team fight | `mobile beam attack combo` |
| 00941 | prehistoric life | `skeletal reconstruction comparison`; `aquatic adaptation` |
| 00881 | school life | `autumn romance aesthetic` |

**2순위는 콘텐츠 목적과 전달 형식입니다.** 플레이·극 장면·움직이는 사물만 보지 않고, 비교·실험·해설·리캡·시각효과 편집인지 함께 보존하도록 해야 합니다. 단, 근거가 없으면 그 목적을 만들지 않습니다.

**3순위는 기법과 전체 스타일입니다.** 의미 있는 행동 수식어·역할·상태는 남기고, 부수적인 복장이나 일상적 동작은 줄입니다. 전체 스타일이 핵심인 콘텐츠는 Context에서 표현하는 방법을 검토할 가치가 있습니다.

곧바로 필드를 많이 늘리거나 토큰 상한을 올리는 것보다, **동일 스키마에서 topics의 선택 기준과 우선순위를 먼저 보완하는 실험**이 적절합니다. 그래도 구체적 초점·표현 스타일이 안정적으로 남지 않으면 짧은 `focus` 또는 `presentation` 필드의 효용을 따로 비교할 수 있습니다. 이번 분석만으로 필드 추가가 반드시 필요하다고 결론내리지는 않습니다.

**최종 판단:** Graph의 개체·행동 표현은 다수 사례에서 유효합니다. 현재 가장 부족한 것은 ‘무엇이 있는가’가 아니라 **‘어떤 관점·목적·스타일로 그것을 보여주는가’**입니다. 이 층위는 상세 줄거리나 대사를 재구성하지 않고도 보완할 수 있습니다. 다만 실제 추천 성능의 개선 여부는 별도 평가가 필요합니다.
